# Bloupunt

A one-tap habit tracker. Single-file HTML PWA, no build step, no dependencies.

- **Max ~3 habits** — the constraint is the feature.
- **One-tap logging** — open, tap, done.
- **Backfill allowed**, streaks reward the chain, "never miss twice" escalates.
- **Encrypted sync** (optional) to a private GitHub repo. localStorage is the source of truth; sync is a non-blocking backup.

Live: https://manaeswolf.github.io/bloupunt/

See [DEVLOG.md](DEVLOG.md) for the design rationale, architecture, and a dated build log.
